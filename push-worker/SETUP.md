# 画面を閉じていても届く通知の設定（Cloudflare Workers・無料）

所要時間の目安：20〜30分。費用は0円です（クレジットカードも不要）。
※ Cloudflare の画面の名前は、変わっていることがあります。表示が違うときは、近い名前のボタンを探してください。

## 1. 通知用の鍵を作る
1. ブラウザで `https://cain218.github.io/seiriken/keygen.html` を開く。
2. 「鍵を作る」を押す。
3. 出てきた長い文字（`{"kty":"EC",...}`）を、「コピーする」で全部コピーする。
   - これは **秘密鍵** です。他の人に見せたり、チャットに貼ったりしないでください。
   - 手順5で貼るまで、メモ帳などに一時的に置いておいてかまいません。

## 2. Cloudflare のアカウントを作る
1. `https://dash.cloudflare.com/sign-up` を開き、メールアドレスとパスワードで登録する。
2. 届いた確認メールのリンクを押して、メールアドレスを確認する。

## 3. Worker（通知を送る小さなプログラム）を作る
1. 左のメニューの「Workers & Pages」を開く。
2. 「Create」→「Create Worker」を押す。
3. 名前を `seiriken-push` にして、「Deploy」を押す。
4. 完了画面の「Edit code」を押す。
5. 左側にある `worker.js` の中身を **すべて消して**、このリポジトリの `push-worker/worker.js` の中身を **すべて貼り付ける**。
6. 右上の「Deploy」を押す。

## 4. 秘密鍵を登録する
1. Worker の画面に戻り、「Settings」→「Variables and Secrets」を開く。
2. 「Add」を押して、次のとおりにする。
   - Type：**Secret**
   - Variable name：`VAPID_PRIVATE_JWK`
   - Value：手順1でコピーした文字
3. 「Deploy」（または「Save」）を押す。

## 5. 動作を確認する
1. Worker のURL（`https://seiriken-push.xxxx.workers.dev`）をコピーする。
2. ブラウザで、そのURLの末尾に `/vapid` を付けて開く。
3. `B` から始まる、87文字くらいの文字が出れば成功です。「VAPID_PRIVATE_JWK が設定されていません」と出たら、手順4をやり直してください。

## 6. 整理券システムにつなぐ
1. Worker のURLを、チャットで教えてください。`docs/firebase-config.js` の `PUSH_WORKER_URL` に入れて公開します（自分で入れる場合は、`window.PUSH_WORKER_URL = 'URL';` にします）。
2. Firebase コンソールの Firestore → ルールに、`firestore.rules` の中身を貼り直して公開する。
3. スタッフ画面の「設定」→「通知サーバーを確認する」で、「つながりました」と出れば完了です。

## お客さんの使い方
- Android：整理券を発行したあとの画面で、「画面を閉じていても通知を受け取る」を押して、通知を許可する。
- iPhone：Safariの共有ボタンから「ホーム画面に追加」して、ホーム画面のアイコンから開き直したあとに、同じボタンを押す（ホーム画面に追加しないと、iPhoneでは届きません）。

## 仕組み（参考）
- 呼び出したとき、再通知したとき、「あと2組」になったときに、スタッフ画面がこの Worker に「この整理券に通知して」と伝えます。
- Worker は、お客さんの端末に、中身のない合図だけを送ります。
- 端末側の `sw.js` が、合図を受けて Firestore を読み、「待機室へお越しください」などの文面を作って表示します。
- スタッフ画面を開いている間だけ、通知が送られます（開いている端末が1台はあること）。
